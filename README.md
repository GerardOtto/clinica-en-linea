Este proyecto implementa un sitio web completo con funciones integradas para la gestión de Pacientes, Especialistas y Administradores, apoyado por una base de datos robusta. El sistema permite a los pacientes registrarse y solicitar citas con especialistas en diversas áreas. Los pacientes pueden adjuntar una ficha médica en formato de imagen, enviar mensajes personalizados a los especialistas y seleccionar horarios convenientes para sus citas.

Los especialistas, por su parte, tienen la capacidad de gestionar las citas solicitadas, modificando su estado a "Aprobada", "Rechazada", o registrando incidencias como "Paciente no asiste a cita" o "Cancelada por paciente". Además, el administrador tiene control absoluto sobre la creación y gestión de especialistas en el sistema, pudiendo administrar sus datos de identificación, contacto, especialidades, foto de perfil y descripciones personales.

El sistema también permite la exportación de todas las citas registradas en la base de datos, junto con sus detalles relevantes, en formato Excel. En cuanto a la seguridad, el sitio implementa medidas efectivas para mantener la privacidad de los datos de los pacientes y asegurar que solo los usuarios autorizados puedan realizar acciones correspondientes a especialistas o administradores.
